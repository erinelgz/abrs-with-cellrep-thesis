\subsection{Abstract}\label{s:artifact_abstract}

To setup a testbed for our ABR evaluation, we used open-source platforms such as Puffer, Mahimahi, and CellReplay. To be able to run this testbed, we had to make some modifications to their source codes in our Ubuntu 24.04 environment. To build Puffer, we had to resolve the \texttt{uint64} errors in several files, which can be easily fixed by adding \texttt{<cstdint>} library on top of the files that produce errors during the \texttt{make} process. In \texttt{opus\_encoder.cc} file, \texttt{av\_register\_all()} call is deprecated, so we removed it. Similarly, we also had to resolve the \texttt{uint64} errors in Mahimahi and CellReplay. To install some of the dependencies that is mentioned in Puffer's documentation, such as Django, we set up a virtual environment and used it when running the web servers. Running Pensieve requires Python 2.7 and TensorFlow, which may not be supported in current systems. We solved this issue by using a Conda environment. Lastly, CellReplay triggered an \texttt{iptables} error, which can be solved by switching to legacy \texttt{iptables}. In the \texttt{nat.cc} file, we undefined \texttt{iptables} and redefined it to use the legacy version.
